# Rocío

Riego inteligente: calcula cuándo y cuánto regar cada planta según el tiempo de tu ubicación (método FAO‑56).

Se publica sola con GitHub Actions como:
- **App web instalable** (GitHub Pages) para Android y iPhone.
- **App de Android** (APK en *Releases*) con avisos diarios.

Para ponerla en marcha, sigue **COMO-PUBLICAR.md**.

Estructura:
- `src/`: código de la app y catálogo de 225 especies.
- `src/pwa/`: archivos de la app instalable.
- `android-overrides/`: icono, splash, permisos y firma de Android.
- `ai-proxy/`: servidor opcional para la IA.
